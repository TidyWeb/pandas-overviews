Pandas · Topic 01 · Summary overview

Turn values into a labelled table.

Topic 1 introduces Pandas’ two core containers: a Series for one labelled sequence, and a DataFrame for several Series sharing the same index.

The values are only part of the object. Pandas lets you keep the values together with row labels, column names, and a readable Series name.

00 / THE ROUTE

Three input shapes, two labelled containers.

Lists, NumPy arrays, and dictionaries already hold values. Pandas adds a structure that makes those values easier to identify and work with.

Python list

Values in order

categories = ["a", "b", "c"]
my_list = [-1, -2, -3]

Three values are available, but no custom row labels have been attached.

NumPy array

Numerical values

arr = np.array([100, 99, 98])

An array supplies numerical values that can become the data in a Series or DataFrame.

Dictionary

Keys and values

my_dict = {
    "Item1": 999,
    "Item2": 888,
    "Item3": 777
}

Keys can become labels while values become the data.

Input

Values in a list, array, or dictionary

Python and NumPy provide the values; a dictionary may also provide names.

→
Pandas

Series → DataFrame

A Series is one labelled sequence. A DataFrame is several Series sharing an index.

Setup first: the lesson imports both packages with import numpy as np and import pandas as pd. The short name pd is then used to call Pandas constructors.

01 / SERIES

One sequence of values, with labels attached.

A Series is similar to a NumPy array, but its index can identify values with numbers or categories instead of positions alone.

Default indexLet Pandas number the rows
scores = pd.Series(data=my_list)
scores

Result: 0 -1, 1 -2, 2 -3; dtype: int64.

Custom labelsSupply the index and name
labelled_scores = pd.Series(
    data=my_list,
    index=categories,
    name="My First Series"
)
labelled_scores

Result: labels a, b, c point to -1, -2, -3; the Series is named My First Series.

data

What values?

The list, array, or other values that the Series will contain.

index

Which label?

The label matched to each value. Three values need three labels.

name

What is this Series called?

A readable name for the one-dimensional object.

Array inputThe labels still come from index=
array_series = pd.Series(
    data=arr,
    index=categories,
    name="Series with array"
)
array_series

Result: a 100, b 99, c 98.

Dictionary inputKeys supply the index automatically
ser = pd.Series(data=my_dict)
ser

Result: Item1, Item2, and Item3 become the index labels for 999, 888, and 777.

Practice pattern from the lesson: changing data= to categories creates a text-valued Series with the default index 0, 1, 2. The constructor stays the same; only the input role changes.

03 / DISPLAY

Read the table as a table, or as text.

The same DataFrame can have different visible representations depending on whether a notebook displays the final expression or Python prints it.

Notebook displayWrite the variable as the final expression
df

Consequence: the notebook renders a formatted, table-like view with row labels and column headers.

Text outputCall print()
print(df)

Consequence: Python emits a text representation. It is useful, but wide tables can become cluttered.

Wide-data example: the lesson creates a 10-row, 40-column DataFrame with np.random.randn(10, 40). A notebook can summarise its shape as 10 rows × 40 columns, while print() lays out many columns as text. This guide calls it wide_df so the earlier df is not silently replaced.

wide_df = pd.DataFrame(data=np.random.randn(10, 40))
wide_df
print(wide_df)
04 / COPY

Keep the original before separate processing.

.copy() creates another DataFrame with the same starting values, so later work can happen on the copy while the original remains available.

Before

df

The original four-row, three-column table is available for comparison or reuse.

.copy()
After

df2

A separate DataFrame begins with the same values and labels.

Create the copyKeep both names visible
df2 = df.copy()
df2
Why this helpsWork on one table, preserve the other

df2 can become the working table for later logic. df still represents the original starting state.

The lesson presents this as a way to process a DataFrame while keeping the original.

State matters: when a notebook reuses the name df for a different table, an earlier command may no longer describe the current object. Separate names such as df and wide_df make the transition visible.

05 / QUICK RECALL

Can you name the job before the constructor?

Try each question first. Reveal the answers only after you have made a prediction; the useful habit is retrieving the structure, not merely recognising the syntax.

  • SeriesWhat does index= add to a sequence of values?
  • DataFrameWhat do dictionary keys become?
  • DisplayWhy might df be clearer than print(df)?
Reveal the answers
  1. index= supplies the labels matched to the values; without it Pandas uses a numeric index.
  2. Dictionary keys become DataFrame column names, and the list values fill those columns.
  3. A notebook renders df as a formatted table, whereas print(df) produces text that can be cluttered when the table is wide.
