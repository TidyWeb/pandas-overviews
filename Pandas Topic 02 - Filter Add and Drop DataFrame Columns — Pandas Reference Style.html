Pandas · Topic 02 · Summary overview

Select the shape, then change the table.

Topic 2 teaches the everyday column operations that turn a DataFrame into a useful working table: select the right shape, calculate a new column, and remove unwanted columns or rows.

Returned versus changed: selecting and dropping normally return a new DataFrame. Adding a column and using inplace=True change the existing DataFrame.

01 / BRACKET SELECTION

One pair or two pairs: what shape do you need?

The brackets are not only selecting the same data in two visual forms. They determine whether the result is a Series or a DataFrame.

One pairOne column becomes a Series
col1_series = df['Col1']
col1_series

Result: a Pandas Series with index labels A to E and the Series name Col1.

Two pairsOne column stays a DataFrame
one_col_frame = df[['Col1']]
one_col_frame

Result: a one-column DataFrame. The inner brackets hold a list of requested column names.

PracticeGrab Col2 as a Series
df['Col2']

Bad practice: df.Col1 may work, but bracket notation is safer and clearer. A future column name could collide with a DataFrame method or attribute.

02 / FILTER

Use .filter() when the column list should be explicit.

The lesson uses .filter() to return DataFrame subsets. For columns, axis=1 tells Pandas which labels to inspect.

One columnReturn a one-column DataFrame
col1_frame = df.filter(
    ['Col1'],
    axis=1
)
col1_frame

Result: a DataFrame containing Col1, not a Series.

Two columnsPass two labels in the list
first_two = df.filter(
    ['Col1', 'Col2'],
    axis=1
)
first_two

Result: a DataFrame containing Col1 and Col2; the original df is unchanged.

Compare the shapes: bracket notation can deliberately return either a Series or a DataFrame. The lesson’s .filter() examples return DataFrames because they are subsetting a table.

The Topic 2 practice asks for the first two columns again using this approach:

df.filter(['Col1', 'Col2'], axis=1)

04 / DROP

Remove columns or rows, then decide whether the result replaces the original.

The .drop() command returns a changed DataFrame unless you reassign it or use inplace=True.

Return a new tableKeep the original df
without_col5 = df.drop(
    labels=['Col5'],
    axis=1
)
without_col5

Consequence: without_col5 has Col1 to Col4. The original df still has Col5.

Change in placeOverwrite the existing table
df.drop(
    labels=['Col5'],
    axis=1,
    inplace=True
)

Consequence: the existing df loses Col5. There is no new DataFrame to assign.

Reassignment is the other durable route: df = df.drop(labels=['Col5'], axis=1) makes the returned four-column table the object referred to by df.

Drop rowsRows are index labels
rows_removed = df.drop(
    labels=['A', 'E'],
    axis=0
)
rows_removed

Result: rows B, C, and D remain in the returned DataFrame. The original df still contains A and E.

Stated practiceDrop B and C without inplace
practice_df = df.drop(
    labels=['B', 'C'],
    axis=0
)
practice_df

Expected result: rows A, D, and E remain. Assignment makes the returned result durable.

Source alignment note: the LMS’s final prompt says “drop rows B and C,” but its displayed worked code drops A and E. Those are different tasks; this guide follows the written prompt in the practice card and keeps the displayed A/E example as a separate demonstration.
