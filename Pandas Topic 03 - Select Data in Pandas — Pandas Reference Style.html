Pandas · Topic 03 · Summary overview

Select data by label, position, or condition.

Topic 3 gives you three routes into a DataFrame: locate visible labels with .loc[], use integer positions with .iloc[], or keep rows that satisfy a Boolean condition with .query().

Three questions: do I know the row or column label, the zero-based position, or the condition that identifies the rows I need?

Choose rows and columns by names such as A or Col3.

Shape follows selection: a single row can become a Series, while lists and slices can preserve a DataFrame. The selector describes both what to read and the shape of the result.

01 / LABELS

Use .loc[] when the labels are known.

The lesson’s label-based route uses visible row labels such as A and column labels such as Col1.

One row labelReturns a Series
df.loc['A']

Result: row A as a Series containing Col1 to Col4. type(df.loc['A']) is pandas.core.series.Series.

Several row labelsReturns a DataFrame
df.loc[['A', 'D']]

Result: a table containing rows A and D and all four columns.

Label slice

df.loc['A':'D']

Includes A, B, C, and D. Label slices include the final label.

or
Label lists

df.loc[['A'], ['Col2', 'Col4']]

Lists preserve a one-row, two-column DataFrame.

# One cell by row label and column label
df.loc['A', 'Col1']

# Selected rows and selected columns
df.loc[['A', 'E'], ['Col1', 'Col3']]

# Inclusive label ranges
df.loc['A':'C', 'Col2':'Col4']

Visible practice outcomes: df.loc['D', 'Col3'] returns -0.9332372163009188. df.loc[['A'], ['Col2', 'Col4']] returns one row and two columns.

02 / POSITIONS

Use .iloc[] when the positions are known.

.iloc[] uses zero-based integer positions. Position 0 is row A; column position 3 is Col4.

Individual positionsRead a row or a cell
df.iloc[0]
df.iloc[0, 2]

Result: the first command returns row A as a Series; the second returns the value at row position 0 and column position 2.

Position listsRead selected areas
df.iloc[[0, 1, 2]]
df.iloc[[0, 1, 2], [2, 3]]

Result: lists select several rows, or several rows and columns, by position.

# Position slices: Python’s stop position is excluded
df.iloc[:3]
df.iloc[:2, 3:]

# Practice: last three rows, last column
df.iloc[-3:, -1:]

03 / CONDITIONS

Use Boolean conditions when the rows must meet a rule.

A condition creates a True or False decision for each row. .query() expresses that rule as readable text and returns the matching rows.

Direct Boolean filterSelect positive Col4 rows
df[df['Col4'] > 0]

Rows kept: A, B, D, and E. Row C is excluded because Col4 is negative.

Readable queryExpress the same rule
df.query("Col4 > 0")

Rows kept: A, B, D, and E. The original df is unchanged.

Both conditionsUse and
df.query(
    "Col4 > 0 and Col1 > 0.5"
)

Rows kept: A and B satisfy both conditions.

Either conditionUse or
df.query(
    'Col2 > 0.8 or Col2 < 0 and Col1 > 0.5'
)

Rows kept: B and E. Without parentheses, and is evaluated before or.

Source expression

Col2 > 0.8 or Col2 < 0 and Col1 > 0.5

Python evaluates the and part first, so B and E remain.

→
Explicit grouping

(Col2 > 0.8 or Col2 < 0) and Col1 > 0.5

The or group is evaluated first, then row B remains after the final restriction.

# Final practice task from the lesson
df.query(
    '(Col3 > 0.4 or Col4 > 0.7) and Col1 < 0.2'
)

Expected result: rows C, D, and E. Parentheses make the first or group explicit before the final and condition.
