Pandas · Topic 04 · Summary overview

Make the row identity work for you.

Topic 4 shows how to inspect an index, reset it, promote a meaningful column into it, and recognise or remove a two-level MultiIndex.

Index choice: a row can be identified by a default position, one meaningful label, or a combination of labels. The structure changes what the table says about each row.

01 / INSPECT + RESET

Inspect the index, then decide what to keep.

.index exposes the current labels. .reset_index() can turn those labels into data or discard them.

df.index

Visible result: an Index containing A, B, C, D, and E. These labels identify the rows separately from Col1 to Col4.

Return a new tableKeep old labels as a column
df_reset = df.reset_index()
df_reset

Result: a new DataFrame with a default 0–4 index and an index column containing A–E. The original df is unchanged.

Change in placeDiscard old labels
df.reset_index(
    drop=True,
    inplace=True
)
df

Result: the existing df now has integer index 0–4. A–E are not kept as a column.

03 / MULTIINDEX

Use a label pair when one label is not enough.

A MultiIndex has more than one level. Here, Category1 and Category2 together identify each row.

np.random.seed(seed=13)
df = pd.DataFrame(data={
    'Col1': np.random.randint(low=10, high=20, size=10),
    'Col2': np.random.randint(low=-10, high=0, size=10),
    'Category1': np.random.choice(['X', 'Y', 'Z'], size=10),
    'Category2': np.random.choice(
        ['a', 'b', 'c', 'd', 'e', 'f', 'g'],
        size=10
    )
})
df.set_index(['Category1', 'Category2'], inplace=True)
df

Inspect structureRead the MultiIndex
df.index

Result: a pandas.MultiIndex containing pairs such as ('Y', 'e') and ('X', 'f').

Inspect namesRead the level names
df.index.names

Result: FrozenList(['Category1', 'Category2']).

One level versus two: a normal index gives each row one label. A MultiIndex gives each row a tuple of labels; the pair carries the hierarchy.

df.reset_index(inplace=True)
df

Flattening result: Category1 and Category2 become ordinary columns again, and the DataFrame returns to a default integer index.
