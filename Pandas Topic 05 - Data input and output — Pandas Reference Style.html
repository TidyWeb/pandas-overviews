Pandas · Topic 05 · Summary overview

Move table data between formats.

Topic 5 shows how to read and write CSV and JSON files, and how to turn every HTML table on a web page into a DataFrame you can inspect.

Output shape matters: CSV and JSON reads normally return one DataFrame. pd.read_html() returns a list of DataFrames because a page may contain many tables.

00 / THE ROUTE

One workflow, three formats.

The lesson moves from local CSV files to JSON, then to HTML pages that may contain many separate tables.

01 / CSVRead or save a table

read_csv returns a DataFrame; to_csv writes one.

02 / JSONChoose a record shape

orient='records' stores rows as record objects.

03 / HTMLCollect page tables

read_html returns a list of DataFrames.

04 / INSPECTChoose the result

Use type, len, and list indexing to find the table you need.

Input versus output: read methods create Python objects from external data. Write methods save a DataFrame to a file when the working environment allows writing.

01 / CSV FILES

Read a CSV, then save it again.

CSV is a text-based table format. The first argument to pd.read_csv() identifies the file or URL to read.

Inspect the folderCheck available files

    'california_housing_test.csv'

df

Result: Pandas reads the CSV and returns a DataFrame.

# Read a CSV hosted at a URL
df = pd.read_csv(
    'https://raw.githubusercontent.com/Code-Institute-Solutions/CSV-datasets/main/UKMacroData.csv'
)
df

# Use Date as the index while reading
df = pd.read_csv(
    'https://raw.githubusercontent.com/Code-Institute-Solutions/CSV-datasets/main/UKMacroData.csv',
    index_col=['Date']
)
df

index_col: the Date column becomes the DataFrame index during the read, rather than remaining an ordinary data column.

SaveWrite CSV locally
df.to_csv('csv_example.csv')

Outcome: writes a CSV file in a writable local working directory.

02 / JSON FILES

Read JSON, then choose its record orientation.

JSON can represent structured records. The lesson reads anscombe.json into a DataFrame and saves rows as record objects.

ReadJSON to DataFrame
df = pd.read_json(
    'anscombe.json'
)
df

Result: a DataFrame created from the JSON file.

WriteDataFrame to records
df.to_json(
    'json_example.json',
    orient='records'
)

Result: a JSON file containing a list of record objects.

DataFrame rows

Columns and values

Each row contains values under named columns.

→
records

[{column: value}, ...]

Each row becomes one JSON object in a list.

Environment reminder: as with CSV output, the LMS notebook cannot write the file. Use the save pattern in a writable local notebook.

03 / HTML TABLES

Read a web page, then find the right table.

An HTML page may contain many tables. pd.read_html() collects them into a list, so the first result is not automatically the table you need.

import requests
from io import StringIO

url = 'https://en.wikipedia.org/wiki/FIFA_World_Cup'

header = {
    "User-Agent": "Mozilla/5.0 (X11; Linux x86_64) "
                  "AppleWebKit/537.36 Chrome/50.0.2661.75 Safari/537.36",
    "X-Requested-With": "XMLHttpRequest"
}

r = requests.get(url, headers=header)
search = pd.read_html(StringIO(r.text))

Key output: search is a Python list. Each item in the list is one DataFrame found in the page.

Inspect the containerCheck type and count
type(search)
len(search)

Outcome: the type is list; len tells you how many tables were found.

Inspect table choicesIndex the list
search[0]
search[24]
search[3]

Outcome: each indexed item is a DataFrame. The lesson chooses search[3].

df = search[3]
df

Source-scope caution: the lesson is teaching how to read a table from a URL, not how to clean it. The chosen table may still have a heading row inside the data or blank HTML cells represented by NaN.
