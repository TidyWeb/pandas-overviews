Pandas · Topic 06 · Summary overview

Missing data needs a reasoned response.

Topic 6 shows how to locate missing values, remove incomplete rows or columns, replace gaps with constants or calculated values, and carry valid observations through a gap.

Inspect first: missing data is a business decision as well as a coding problem. Count it, understand the variable, then choose the least misleading treatment.

01 / DetectMeasure the gaps

Use .isnull() and .sum() to locate and count missing values.

02 / DropRemove incomplete data

Use .dropna() with direction, threshold, or subset rules.

03 / FillReplace missing values

Use constants, means, or business-defined values with .fillna().

04 / CarryUse nearby observations

Use forward or backward fill only when the variable’s meaning supports it.

NaN is not zero: it means no value is stored for that observation. The treatment should preserve the meaning of the variable.

01 / DETECT

Find the gaps before deciding what to do.

.isnull() returns a Boolean mask; adding .sum() turns the mask into column-level counts.

Where?Create a missing-value mask
df.isnull()

Result: True marks missing cells; False marks values that are present.

How many?Count by column
df.isnull().sum()

Result: A has 1 missing value, B has 2, and C has 0.

ColumnMissing countMeaning
A1One observation has no A value.
B2Two observations have no B value.
C0Every C value is present.

Practice dataset: the lesson loads UK_MacroDataMissingValues.csv into df_practice and asks you to run df_practice.isnull().sum(). Bank Rate is recorded only when it changes, while GDP and CPI are missing for parts of 2020.

02 / DROP

Drop data with a clear rule.

.dropna() returns a changed DataFrame by default. It does not overwrite the original unless you choose to do so.

RowsDrop any incomplete row
df.dropna()

Result: only row 0 remains. The default axis=0 means rows.

ColumnsDrop any incomplete column
df.dropna(axis=1)

Result: only column C remains. axis=1 means columns.

Rule

df.dropna(thresh=2)

Keep rows with at least two non-missing values.

→
Result

Rows 0 and 2

Row 1 has only one present value, so it is dropped.

Selected variablesCheck only A
df.dropna(
    subset=['A']
)

Result: rows missing A are removed; B may still be missing.

PracticeTarget one business variable
df_practice.dropna(
    subset=[
        'Gross Fixed Capital Formation (Investments)'
    ]
)

Result: rows missing that selected variable are removed from the returned DataFrame.

State reminder: without inplace=True or reassignment, df remains unchanged.

03 / FILL

Replace gaps with a value that means something.

.fillna() can use a constant, a calculated value, or a domain-specific replacement. The choice can change a column’s type and interpretation.

Text constantFill every gap
df.fillna(
    value='Constant_Value'
)

Result: missing cells show the text placeholder. Numeric columns may become object-like.

Numeric constantFill with -4
df.fillna(value=-4)

Result: missing cells become -4. That number is only appropriate if its meaning is defensible.

Present A values

2.0 and 1.0

The mean is 1.5.

→
Filled A

NaN becomes 1.5

The missing A value receives the column mean.

# Source lesson pattern
df['A'].fillna(
    value=df['A'].mean(),
    inplace=True
)

# Clear assignment form
df['A'] = df['A'].fillna(
    df['A'].mean()
)

Practice route: for the 2019–2021 slice of df_practice, fill missing CPI with its local mean and fill missing GDP (£ m) with 558480, then display the DataFrame.

df_practice['CPI'].fillna(
    value=df_practice['CPI'].mean(),
    inplace=True
)
df_practice['GDP (£ m)'].fillna(
    value=558480,
    inplace=True

04 / CARRY VALUES

Carry a nearby value only when the sequence supports it.

Forward fill uses the previous valid observation; backward fill uses the next valid observation. Both are meaning-dependent decisions.

ForwardUse the last valid value
df.ffill()

For this table: A row 1 becomes 2.0 and B rows 1–2 become 1.0.

BackwardUse the next valid value
df.bfill()

For this table: A row 1 becomes 1.0; B stays missing because there is no later valid B value.

MethodDirectionKey limitation
df.ffill()Previous valid observation forwardCannot fill a leading gap without an earlier value.
df.bfill()Next valid observation backwardCannot fill a trailing gap without a later value.

Source-version note: the LMS writes df.fillna(method='ffill') and df.fillna(method='bfill'). In Pandas 3.0.1, that method argument raises a TypeError; use .ffill() and .bfill() instead.
