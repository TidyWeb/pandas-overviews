Pandas · Topic 08 · Summary overview

Change the shape
without losing the table.

Topic 8 is about making a DataFrame easier to work with: give columns useful names, keep only the kinds of columns you need, and turn the values into a NumPy array when another tool requires one.

The values do not have to change. This topic changes labels around the values, selects a useful subset of columns, or removes DataFrame labels when moving into a positional NumPy array.

00 / THE STARTING POINT

One table, three jobs.

The LMS uses generic columns such as Col1 and Col3. This chapter uses a small customer table instead, so the commands have a visible purpose.

01 / RenameMake labels human

Replace generic or awkward column names with the names that make the table understandable.

02 / SelectKeep the matching types

Ask Pandas for only number, text/object, Boolean, datetime, or other stored types.

03 / ConvertTake the values out

Move from a labelled DataFrame to a position-based NumPy array when that is what a later tool needs.

01 / RENAME COLUMNS

Are you renaming all labels, or only some?

That is the first decision. The two commands look related but serve different jobs.

Every columnAssign a complete label list
customers.columns = [
    "ClientID",
    "TargetValue",
    "Children",
    "CreditLimit",
    "IsActive"
]
Selected columnsMap the old name to the new name
renamed_customers = customers.rename(columns={
    "CLIENTNUM": "ClientID",
    "Attrition_Flag": "TargetValue",
    "Dependent_count": "Children"
})
Before

customers

Still has original labels, including CLIENTNUM.

→
After

renamed_customers

Has ClientID, TargetValue, and Children. Unmapped labels stay the same.

The important difference: assigning to customers.columns changes that DataFrame. customers.rename(...) returns a renamed result. Put a new variable name to the left of = if you want to keep the original table unchanged.

The course’s inplace=True form

customers.rename(
    columns={"CLIENTNUM": "ClientID"},
    inplace=True
)

Visible consequence: the name customers now refers to the changed table. No new renamed DataFrame is returned to assign. In new work, the explicit new_table = old_table.rename(...) form is usually easier to read.

02 / SELECT BY TYPE

Ask for the columns that are stored in a particular way.

select_dtypes() does not decide what a column means in the real world. It inspects how Pandas has stored it, then returns the matching columns.

Numbers

Keep number-stored columns

customers.select_dtypes(
    include="number"
)

Returns numeric columns such as Dependent_count and Credit_Limit. It can also include a numerical-looking ID.

Text / object

Keep text-like object columns

customers.select_dtypes(
    include="object"
)

Returns columns such as Attrition_Flag, where text values act as repeated labels.

Boolean

Keep True / False columns

customers.select_dtypes(
    include="boolean"
)

Returns Boolean columns such as IsActive.

“Object” is not a perfect synonym for “categorical.” In the course’s toy table, text labels such as A, B, C, and D are object-stored and act as categories. But a numerical code such as 1 = Bronze, 2 = Silver can also be categorical in meaning.

Several wanted typesPass a list to include=
customers.select_dtypes(
    include=["boolean", "number"]
)
Reverse the questionLeave a type out with exclude=
customers.select_dtypes(
    exclude="number"
)

The first form keeps either requested type. The second keeps everything except number-stored columns.

03 / RESET THE INDEX

Move the row labels into the table.

Topic 8 uses dates as the DataFrame’s index. Resetting the index makes those dates a normal column, which means they can then be selected by stored datetime type.

Before

Dates down the left

The dates are row labels — an index — not an ordinary data column.

→
After reset_index()

Dates become a column

The former index becomes a column called index; rows receive a new 0, 1, 2, … index.

Change the shapeReturn a new DataFrame with an index column
customers_with_index_column =     customers.reset_index()
Now select the datesFind datetime-stored columns
customers_with_index_column     .select_dtypes(include="datetime")

Visible consequence: select_dtypes(include="datetime") finds columns Pandas has stored as dates/times. It does not simply look for strings that resemble dates.

04 / NUMPY ARRAY

Leave the labels behind; keep the values.

A DataFrame is a table of values with row and column labels. A NumPy array is a position-based block of values. That is why the same information can look simpler after conversion.

DataFrame

Values + labels

Cell values, column names, and a row index travel together.

→
NumPy array

Values in positions

The array retains cell values. The DataFrame’s row index and column names are not part of it.

Recommended.to_numpy() is a method
customer_array =     customers.to_numpy()

# parentheses: call the method
# options are available when needed
Older shorthand.values is a property
customer_array =     customers.values

# no parentheses: retrieve a property
# no arguments can be supplied here
Method

customers.to_numpy()

Parentheses mean “perform this operation.” It can take useful options when needed:

customers.select_dtypes(
    include="number"
).to_numpy(dtype=float)

customers.to_numpy(copy=True)
Property

customers.values

This retrieves the table’s NumPy representation directly. It produces almost the same basic outcome, but it has no parentheses and no options.

The preferred form for new code is .to_numpy().
