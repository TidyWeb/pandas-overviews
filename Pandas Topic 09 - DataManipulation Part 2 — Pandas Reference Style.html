what it says.

Topic 9 prepares data for analysis: replace coded labels, set fitting data types, and remove only records that repeat according to the real business rule.

Cleaning is not cosmetic. Each command makes an assumption about what a value or a row means. Inspect the effect before keeping the change.
DecisionReplaceTypesDuplicatesRecall
00 / DECISION

Three checks before analysis.

Values can be unclear, types can misrepresent their role, and repeated rows can inflate totals. Each problem needs a different command.

01 / ValuesReplace a code

Map old labels to values needed for a clear category or later calculation.

02 / TypesStore by meaning

Set IDs, categories, quantities, and Boolean flags deliberately.

03 / RowsUse a business key

Define what makes a record unique before identifying or removing repeats.

01 / REPLACE

Map existing values to new meaning.

A dictionary makes the translation visible: keys are current values and values are their intended replacements.

The mappingDescribe the translation
map_dict = {'A': 'Nice', 'B': 'Super',
            'C': 'Amazing', 'D': 'Incredible'}
Apply itReplace one column
df['Col3'].replace(
    to_replace=map_dict,
    inplace=True
)

The lesson also maps X, Y, and Z in Col6 to numeric values and checks the result with df.dtypes.

Bank Churners practice: inspect Attrition_Flag with .unique(), then replace Attrited Customer with 1 and Existing Customer with 0.
Why inspect unique values first?
The mapping must match the values actually present. A spelling, spacing, or label difference not in the dictionary will not be replaced.
02 / TYPES

A number can be an ID, not a measurement.

Stored type and analytical meaning are different. A quality code from 1 to 3 may be numeric-looking but represent named categories.

Lesson tableConvert a category code
df = df.astype({'Col5': 'object'})
df.dtypes
Churn practiceConvert two columns
df_practice = df_practice.astype({
    'CLIENTNUM': 'category',
    'Attrition_Flag': 'bool'
})
Assignment matters: .astype() returns a converted object. Keep it by assigning that result back to the DataFrame or column.

Validate with df_practice[['CLIENTNUM', 'Attrition_Flag']].info().

03 / DUPLICATES

Repeated according to which rule?

Two rows may differ but still be duplicates for the task. Choose the column or combination that represents one real-world record.

Inspect later repeatsFirst copy is kept
df[df.duplicated(
    subset=['Name']
)]
Inspect every memberSee the group
df[df.duplicated(
    subset=['Name'], keep=False
)]

The lesson table repeats John and Marie. CustomerRate differs, but each Name is stated to be unique.

df.drop_duplicates(subset=['Name'], inplace=True)
Online Retail practice: use the combined key ['InvoiceNo', 'StockCode', 'CustomerID']. Inspect with keep=False before calling drop_duplicates(subset=key).
Why not drop first?
Removing data is a decision. Looking at every marked record first checks that the uniqueness rule is correct and that the retained row is appropriate.
04 / RECALL

A short, reliable cleaning route.

  • 1. Name the meaningWhat should the values or rows represent?
  • 2. Inspect firstUse unique(), dtypes, info(), or duplicated(..., keep=False).
  • 3. Change deliberatelyUse replace(), astype(), or drop_duplicates() with an explicit rule.
Quick recall: .replace() changes values; .astype() changes storage type; .duplicated() returns a Boolean mask; .drop_duplicates() removes rows using the selected subset.
