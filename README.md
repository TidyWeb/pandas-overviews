# Pandas Overviews

A calm, beginner-friendly set of Pandas topic overviews.

Start with [index.html](index.html): it explains what Pandas is for, where each topic fits, and which guide to open when your table starts acting suspiciously.

These guides cover the practical jobs:

- build and select tables;
- inspect what is actually in them;
- tidy missing, repeated, or oddly stored data;
- prepare data for analysis.

You do not need to memorise every command. Find the job, open the matching topic, and let Pandas do the heavy lifting.
