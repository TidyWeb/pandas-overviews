Pandas - your working map

Tables, made less frightening.

Pandas is a practical tool for working with table-shaped data. It helps you look at a table, ask useful questions, tidy what needs tidying, and prepare it for analysis. You do not need to know every command before you begin.

This is a map, not a test. Use it to understand the broad jobs Pandas can do. When a real task appears, come back here, recognise the job, and open the matching topic.

01 / THE JOURNEY

From a table to a useful answer.

The individual commands are small. The value comes from seeing where each one fits in the overall route.

StartBuild

Turn values into a labelled table so the rows and columns have names.

ChooseSelect

Keep the rows and columns relevant to the question you are trying to answer.

UnderstandExplore

Check shape, types, categories, distributions, and relationships before trusting conclusions.

PrepareTidy

Handle files, indexes, missing values, labels, types, and duplicated records.

UseAnalyse

Work from a clearer, more trustworthy table when you calculate, compare, or visualise.

The simple idea: most real tasks begin with one question: “What do I need this table to do?” The topics below help you match that job to a small group of tools.

03 / RETURN

When a real task lands, do this.

You do not need a command in your head before you can begin. Start with the human question, then use the map to locate the tool family.

1. Name the job

Are you trying to load a file, find rows, inspect what is there, change values, or make the table more trustworthy?

2. Find the stage

Use the journey above, then open the topic card whose description matches your job.

3. Use the reference

The topic page gives the commands, examples, and consequences. Search within it when you need a specific tool.

What am I expected to remember?

Remember the broad jobs, not every piece of syntax:

  • Tables have rows, columns, labels, and types.
  • You can select, inspect, tidy, and prepare them.
  • Each job has a small group of Pandas tools.
  • You can return to this map whenever you need the right group.
A good next step is always small. Open one topic, follow one example, and relate it to the table in front of you. That is how the command becomes memorable.
